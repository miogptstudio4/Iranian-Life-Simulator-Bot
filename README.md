# شبیه‌ساز زندگی یک ایرانی  
### Iranian Life Simulator v1.1

شبیه‌ساز متنی سخت از زندگی در ایران با ذخیره دائمی روی **PostgreSQL**.

---

## ذخیره دائمی (PostgreSQL)

اطلاعات بازیکن‌ها دیگر پاک نمی‌شود.

### راه‌اندازی دیتابیس

```bash
# نصب وابستگی
pip install -r requirements.txt

# ساخت دیتابیس در PostgreSQL
sudo -u postgres createdb iranian_life_sim

# تنظیم متغیرهای محیطی (اختیاری)
export DB_HOST=localhost
export DB_PORT=5432
export DB_NAME=iranian_life_sim
export DB_USER=postgres
export DB_PASSWORD=your_password
```

یا از فایل `.env.example` کپی بگیرید.

## سیستم بچه‌دار شدن با زمان و شانس (به‌روز)

1. **تلاش (ارضا / نزدیکی)**  
   - شانس بارداری بستگی داره به: سن، سلامت، روحیه مادر  
   - شانس معمولاً بین ۲٪ تا ۲۸٪ در هر تلاش

2. **صبر برای نتیجه**  
   - بین ۱۰ تا ۴۵ روز (گاهی تا ۶۰ روز) طول می‌کشه تا بفهمی باردار شدی یا نه  
   - شانس و بدشانسی روی این مدت تأثیر داره

3. **بارداری**  
   - حدود ۲۷۰ روز (۹ ماه)  
   - هر ماه سلامت و روحیه کم می‌شه و هزینه داره

4. **زایمان**  
   - ریسک و هزینه بسته به محل زایمان

## دیپلوی روی Render.com

### روش ۱ — با Blueprint (پیشنهادی)

1. ریپو را روی GitHub بگذار
2. به [Render Dashboard](https://dashboard.render.com) برو
3. **New → Blueprint**
4. ریپو را وصل کن (فایل `render.yaml` را می‌خواند)
5. متغیرها را پر کن:
   - `TELEGRAM_BOT_TOKEN` → توکن از @BotFather
6. Deploy

یک **Worker** برای ربات + یک **PostgreSQL** رایگان ساخته می‌شود.

### روش ۲ — دستی

1. **New → Background Worker**
2. Runtime: Python
3. Build: `pip install -r requirements.txt`
4. Start: `python bot.py`
5. Environment:
   - `TELEGRAM_BOT_TOKEN` = توکن ربات
   - `DB_HOST` / `DB_NAME` / `DB_USER` / `DB_PASSWORD` (اگر دیتابیس جدا ساختی)

### نکات
- پلن Free ممکن است بعد از مدتی Sleep شود؛ برای ربات بهتر است Worker همیشه روشن بماند
- توکن را فقط در Environment Variables بگذار، داخل کد نگذار
