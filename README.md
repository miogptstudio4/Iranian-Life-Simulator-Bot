# شبیه‌ساز زندگی یک ایرانی  
### Iranian Life Simulator v1.1

شبیه‌ساز متنی سخت از زندگی در ایران با ذخیره دائمی روی **PostgreSQL**.

---

## ذخیره دائمی (PostgreSQL)

اطلاعات بازیکن‌ها دیگر پاک نمی‌شود.

### راه‌اندازی دیتابیس

```bash
# نصب وابستگی
pip install -r requirements.txt

# ساخت دیتابیس در PostgreSQL
sudo -u postgres createdb iranian_life_sim

# تنظیم متغیرهای محیطی (اختیاری)
export DB_HOST=localhost
export DB_PORT=5432
export DB_NAME=iranian_life_sim
export DB_USER=postgres
export DB_PASSWORD=your_password
```

یا از فایل `.env.example` کپی بگیرید.

### جداول ساخته‌شده
- `players` → تمام اطلاعات شخصیت
- `game_admins` → لیست ادمین‌ها (ادمین اصلی: `6227792513`)

### رفتار ذخیره
- ذخیره خودکار هنگام حرکت (۲۵٪ شانس)
- ذخیره هنگام خروج از نقشه
- ذخیره در پایان بازی
- امکان ادامه بازی قبلی با وارد کردن `player_id`

## سیستم بچه‌دار شدن با زمان و شانس (به‌روز)

1. **تلاش (ارضا / نزدیکی)**  
   - شانس بارداری بستگی داره به: سن، سلامت، روحیه مادر  
   - شانس معمولاً بین ۲٪ تا ۲۸٪ در هر تلاش

2. **صبر برای نتیجه**  
   - بین ۱۰ تا ۴۵ روز (گاهی تا ۶۰ روز) طول می‌کشه تا بفهمی باردار شدی یا نه  
   - شانس و بدشانسی روی این مدت تأثیر داره

3. **بارداری**  
   - حدود ۲۷۰ روز (۹ ماه)  
   - هر ماه سلامت و روحیه کم می‌شه و هزینه داره

4. **زایمان**  
   - ریسک و هزینه بسته به محل زایمان

## دیپلوی روی Render.com

### روش ۱ — با Blueprint (پیشنهادی)

1. ریپو را روی GitHub بگذار
2. به [Render Dashboard](https://dashboard.render.com) برو
3. **New → Blueprint**
4. ریپو را وصل کن (فایل `render.yaml` را می‌خواند)
5. متغیرها را پر کن:
   - `TELEGRAM_BOT_TOKEN` → توکن از @BotFather
6. Deploy

یک **Worker** برای ربات + یک **PostgreSQL** رایگان ساخته می‌شود.

### روش ۲ — دستی

1. **New → Background Worker**
2. Runtime: Python
3. Build: `pip install -r requirements.txt`
4. Start: `python bot.py`
5. Environment:
   - `TELEGRAM_BOT_TOKEN` = توکن ربات
   - `DB_HOST` / `DB_NAME` / `DB_USER` / `DB_PASSWORD` (اگر دیتابیس جدا ساختی)

### نکات
- پلن Free ممکن است بعد از مدتی Sleep شود؛ برای ربات بهتر است Worker همیشه روشن بماند
- توکن را فقط در Environment Variables بگذار، داخل کد نگذار
- ادمین اصلی: `6227792513`


## نسخه جدید — چرخه واقعی زندگی، خانه و خانواده

- شخصیت جدید ابتدا در روایت از **۰ سالگی** متولد می‌شود.
- در شروع، مشخصات شخصیت، شهر، خانواده، اعضای خانواده و وضعیت خانه معرفی می‌شود.
- بعد از این معرفی، شخصیت به **۱۰ سالگی** می‌رسد و بازی اصلی آغاز می‌شود.
- از اینجا به بعد، **هر ۱۰ روز داخل بازی = یک سال از عمر شخصیت** است.
- سن در PostgreSQL ذخیره می‌شود و با ادامه بازی از بین نمی‌رود.
- سیستم خانه: نوع خانه، سطح، اتاق‌ها، تمیزی، راحتی و وضعیت آب/برق/گاز/اینترنت.
- سیستم خانواده: پدر/مادر/خواهر/برادر، سن، شغل و میزان رابطه.
- رویدادهای روزمره خانوادگی و استراحت در خانه.
- دستورات جدید ربات: `خانه`، `خانواده`، `زندگی` و `استراحت`.

## نسخه ارتقایافته زندگی
- شروع بازی اصلی از ۱۷ سالگی
- هر ۱۰ روز بازی = ۱ سال زندگی
- سیستم مغازه و خرید با دکمه‌های تلگرام
- کوله‌پشتی و ذخیره موجودی در PostgreSQL
- سفر بین شهرهای ایران با هزینه و گذر زمان
- بارگذاری فهرست شهرهای ایران از دیتای ۱۴۰۲؛ در نبود اینترنت از فهرست داخلی استفاده می‌شود

- مدرسه، دیپلم و دانشگاه

- اجاره و خرید خانه

- راه‌اندازی و فعالیت کسب‌وکار
- بورس و خرید/فروش سهام شبیه‌سازی‌شده
- مالیات و بدهی مالیاتی

## تنظیمات Render — نسخه آماده اجرا

این نسخه برای **Render Web Service** آماده شده است:

- `startCommand`: `python bot.py`
- پورت از متغیر محیطی `PORT` خوانده می‌شود.
- سرور HTTP روی `0.0.0.0:$PORT` اجرا می‌شود.
- مسیر سلامت: `/health`
- ربات تلگرام هم‌زمان با polling اجرا می‌شود.
- اطلاعات PostgreSQL از `fromDatabase` به‌صورت خودکار به سرویس منتقل می‌شود.
- نسخه Python روی 3.13 تنظیم شده است.

پس از Deploy، Render باید health check مسیر `/health` را با پاسخ 200 دریافت کند. طبق مستندات Render، Web Service باید روی `0.0.0.0` و پورت `PORT` گوش دهد و `healthCheckPath` می‌تواند برای بررسی سلامت سرویس استفاده شود.

**متغیر لازم:**
- `TELEGRAM_BOT_TOKEN`

> نکته: سرویس رایگان Render محدودیت‌هایی مثل sleep شدن Web Service و محدودیت‌های دیتابیس رایگان دارد؛ برای نگهداری دائمی اطلاعات، محدودیت‌های Free PostgreSQL را در نظر بگیر.
